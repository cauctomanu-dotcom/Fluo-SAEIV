FLUO SAEIV V18 — FILTRE LIGNES + CROSSWAY AJUSTÉ

NOUVEAUTÉS V18
- Le marqueur Iveco Crossway réel est réduit à environ 45 % de la taille V17.
- En paysage smartphone : environ 18 x 57 px au lieu de 36 x 114 px.
- En autres vues : environ 20 x 64 px au lieu de 40 x 127 px.
- Le marqueur conserve exactement l'image Fluo Grand Est fournie et son orientation.
- Nouveau filtre après Département : Lignes régulières / Lignes scolaires / Toutes les lignes.
- Le choix est mémorisé sur le téléphone.
- Le même filtre est ajouté à l'onglet Calcul horaires.
- La détection scolaire se base sur les libellés GTFS usuels (SCOLAIRE, ECOLE, COLLEGE, LYCEE, RPI, lignes S/SC/SCO...).
- « Toutes les lignes » reste disponible si un libellé GTFS ne permet pas de classer correctement une ligne.
- Toutes les fonctions V17 sont conservées. Aucun serveur/Supabase n'est ajouté.
